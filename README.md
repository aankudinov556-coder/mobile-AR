<h1 align="center">Вера — чиби ИИ-ассистент для Windows и Android</h1>

<p align="center">
Маленькая пиксельная девушка с белыми волосами: на ПК живёт на рабочем столе, на телефоне сидит на панели чата и болтает ножками.<br>
Подкалывает, говорит голосом, сама ставит напоминания и напоминает вовремя, управляет ПК или телефоном и помнит, что ты ей рассказывал.
</p>

> Android — разреши установку из этого источника.

## Первый запуск

Выбери один из двух путей (или готовый набор в настройках):

- **Бесплатно и офлайн (ПК):** **Настройки → Локальный ИИ** → скачай рекомендованную модель.
  Для голоса — Whisper, Piper и Vosk там же, в разделе «Голос». Ключи не нужны, переписка не покидает компьютер.
- **Через облако:**
  1. вставь ключ в **Настройки → API-ключи**: **OpenRouter** (сотни моделей по одному ключу), **Anthropic** (Claude) или **OpenAI**;
  2. для живого голоса и распознавания — ключ **OpenAI** (или **Groq** для распознавания и бесплатный голос).

Ключи хранятся только на устройстве в зашифрованном виде (Windows DPAPI / Android Keystore).

## Что умеет

- **Чат** с OpenRouter, Anthropic (`claude-opus-5-5` по умолчанию), OpenAI, своим сервером (Ollama, LM Studio)
  или **встроенной моделью на ПК** (llama.cpp: Qwen, Gemma или свой `.gguf`). Стриминг, Markdown, картинки и скриншоты.
- **Документы**: PDF, DOCX, TXT/MD/CSV и код — 📎 или перетаскиванием в чат.
- **Поиск в интернете** для любой модели: без ключа через DuckDuckGo и Википедию, с ключом — Tavily или Brave.
- **Характеры**: дерзкая (подкалывает), милая, деловая, цундере + свой промпт. Мимика меняется по ответу модели.
- **Напоминания, которые Вера ставит сама**: «напомни через 20 минут…», «по будням в 9:00…». В нужное время — уведомление,
  звук, голос и кнопки «Готово / +10 мин». На Android — системные будильники, срабатывают даже при закрытом приложении.
- **Голос**:
  - распознавание — OpenAI, Groq, **Whisper офлайн** на ПК, на Android — средствами телефона;
  - озвучка — OpenAI, ElevenLabs, **Piper офлайн**, системный голос; рот двигается в такт;
  - рация по кнопке или горячей клавише;
  - активация словом «Вера»: на ПК имя слушает **Vosk** без интернета, речь от шума отличает **Silero VAD**.
- **Два скина** на ПК: пиксельная Вера и «halo». Когда скучно — садится на пол.
- **ПК**: сайты, поиск, программы из меню «Пуск», папки, громкость и музыка, блокировка, буфер обмена, скриншот экрана,
  сведения о ПК, команды PowerShell (выключены по умолчанию, каждая с подтверждением).
- **Телефон**: открыть приложение или сайт, позвонить (набор номера), карты, поделиться текстом, буфер обмена, фонарик, настройки.
- **Долгая память**: Вера запоминает важное о тебе; можно посмотреть и отредактировать.
- **Погода** (Open-Meteo, без ключа).

## Горячие клавиши (Windows, меняются в настройках)

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+V` | Показать / скрыть чат |
| `Ctrl+Alt+Space` | Говорить с Верой (ещё раз — закончить) |
| `Ctrl+Alt+S` | «Что у меня на экране?» |

## Устройство проекта (.NET 10)

```
Vera.Core/          общая библиотека: провайдеры LLM (Anthropic SDK, OpenAI SDK, OpenRouter), цикл агента,
                    инструменты, напоминания, память, характеры, STT/TTS, VAD-запись, Markdown, мимика спрайта
Vera.Core.Tests/    юнит- и интеграционные тесты (мок-серверы OpenAI и Anthropic)
Vera.LocalAI/       только ПК: встроенная LLM (LLamaSharp), Whisper.net, Piper, Silero VAD, Vosk, каталог и загрузка моделей
Vera.LocalAI.Tests/ тесты локального ИИ (подделка движка + настоящий llama.cpp на крошечной модели, см. tools/make_tiny_gguf.py)
Vera.Desktop/       Windows (WPF): Вера на рабочем столе, чат, трей, горячие клавиши, инструменты ПК, установщик
Vera.Mobile/        Android (.NET MAUI): чат с Верой на панели ввода, будильники, голос, инструменты телефона
assets/vera/        слои пиксель-арта 64×72 (генерирует tools/gen_sprite.py)
```

```bash
dotnet test Vera.Core.Tests                                   # тесты ядра
dotnet test Vera.LocalAI.Tests                                # тесты локального ИИ
dotnet run --project Vera.Desktop                             # Windows
dotnet build Vera.Mobile -f net10.0-android -t:Run            # Android (нужен workload maui-android и Android SDK)
python3 tools/gen_sprite.py                                   # перерисовать спрайты (Python 3 + Pillow)
```

Версия — в `Directory.Build.props`. Пуш запускает `desktop.yml`: тесты, портативная сборка, пре-релиз `v<версия>`.
APK (`android.yml`) сейчас собирается только вручную.

Старая Electron-версия (v1.0.0) осталась в релизе `v1.0.0` и в истории git.

## Приватность

- Сообщения уходят только выбранному провайдеру, голос — выбранному сервису распознавания и синтеза.
  Со встроенной моделью, Whisper, Piper и Vosk всё остаётся на компьютере.
- Скриншот делается только по твоей просьбе.
- История, память и напоминания хранятся на устройстве (Windows: `%APPDATA%\VeraAssistant`, модели — `%LOCALAPPDATA%\VeraAssistant\models`).
