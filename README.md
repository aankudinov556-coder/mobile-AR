<h1 align="center">Вера — чиби ИИ-ассистент для Windows</h1>

<p align="center">
Маленькая пиксельная девушка с белыми волосами живёт у тебя на рабочем столе, подкалывает, болтает голосом,<br>
сама ставит напоминания и напоминает вовремя, открывает программы, смотрит на экран и помнит, что ты ей рассказывал.
</p>

---

## Скачать

Готовый установщик собирается автоматически в GitHub Actions — смотри раздел **Releases** репозитория:

| Файл | Что это |
|---|---|
| `Vera-Setup-1.0.0.exe` | Установщик (ярлык на рабочем столе и в меню «Пуск», можно выбрать папку) |
| `Vera-Portable-1.0.0.exe` | Портативная версия, без установки |

> Установщик не подписан цифровой подписью, поэтому SmartScreen может предупредить: **«Подробнее» → «Выполнить в любом случае»**.

## Первый запуск

1. Запусти Веру — она появится в правом нижнем углу экрана, а окно откроется на вкладке **Настройки**.
2. Вставь хотя бы один ключ:
   - **OpenRouter** — один ключ на сотни моделей (по умолчанию `openai/gpt-5-mini`);
   - **Anthropic** — модели Claude (по умолчанию `claude-opus-5-5`);
   - **OpenAI** — модели GPT, а ещё **голос** (TTS) и **распознавание речи** (STT).
3. Выбери провайдера и модель (кнопка ⟳ загружает список моделей).
4. Готово — пиши в чат или жми `Ctrl+Alt+Space` и говори.

Ключи хранятся только на твоём компьютере, зашифрованные через Windows DPAPI (`safeStorage`).

## Что умеет

### 💬 Чат и характер
- Три провайдера: **OpenRouter**, **Anthropic**, **OpenAI** — переключаются на лету.
- Стриминг ответов, Markdown, блоки кода с кнопкой «Копировать».
- Характеры: **дерзкая (подкалывает)**, милая, деловая, цундере + свой системный промпт.
- Мимика: модель ставит тег эмоции, Вера меняет выражение лица и позу (ухмылка, смех, «хи-хи» ладошкой у рта, задумчивость, удивление, смущение…).
- Опционально — поиск в интернете (Anthropic web search / плагин web у OpenRouter).

### ⏰ Напоминания (Вера ставит их сама)
- «Напомни через 20 минут выключить чайник», «каждый будний день в 9:00 — стендап», «завтра в 18 позвонить маме».
- Вера вызывает инструмент `create_reminder`, а в нужное время:
  уведомление Windows + звуковой сигнал + Вера говорит голосом + пузырь с кнопками **Готово / +10 мин / +1 час**.
- Повторы: каждый час, день, по будням, неделю, месяц.
- Пропущенные (пока ПК был выключен) напоминания срабатывают при следующем запуске.
- Отдельная вкладка: список, ручное добавление, удаление; Вера умеет показывать, менять и удалять напоминания.

### 🎙️ Голос
- **STT**: OpenAI (`gpt-4o-mini-transcribe` / `gpt-4o-transcribe` / `whisper-1`) или **Groq Whisper** (быстро и дёшево).
- **TTS**: OpenAI (`gpt-4o-mini-tts` с инструкцией интонации под характер), **ElevenLabs**, или бесплатный системный голос Windows.
- Озвучка начинается по первым предложениям, не дожидаясь конца ответа; рот Веры двигается в такт звуку.
- **Рация**: `Ctrl+Alt+Space` — начать говорить, конец фразы определяется по паузе (или нажми ещё раз).
- **Голосовая активация**: «Вера, …» — микрофон слушает постоянно (VAD), фраза с её именем выполняется как команда.

### 🖥️ Управление ПК
- Открыть сайт / поиск (Google, Яндекс, YouTube, Википедия…), запустить программу (ищет в меню «Пуск» + свои ярлыки), открыть папку.
- Медиа: пауза/play, следующий/предыдущий трек, громкость (в т.ч. «поставь 30%»), без звука.
- Заблокировать ПК, свернуть все окна, диспетчер задач, параметры Windows.
- Буфер обмена (прочитать/записать), сведения о ПК (CPU, RAM, батарея), погода (Open-Meteo, без ключа).
- **Скриншот**: «Вера, что у меня на экране?» (`Ctrl+Alt+S`) — снимок уходит в vision-модель.
- Команды PowerShell — по умолчанию **выключены**, а если включить — каждая подтверждается.

### 🧠 Долгая память
- Вера сама запоминает важные факты о тебе (`remember`) и забывает по просьбе (`forget`).
- Вкладка «Память»: посмотреть, отредактировать, удалить, добавить вручную.

### 🧸 Питомец на рабочем столе
- Прозрачное окно поверх всех, клики проходят сквозь пустые места.
- Перетаскивание мышкой, клик — чат, двойной клик — потыкать, правый клик — меню.
- Моргает, дышит, засыпает ночью, иногда болтает сама (без запросов к API), реагирует на перетаскивание.
- Размер 2×–6×, иконка в трее, автозапуск с Windows.

## Горячие клавиши (меняются в настройках)

| Сочетание | Действие |
|---|---|
| `Ctrl+Alt+V` | Показать / скрыть чат |
| `Ctrl+Alt+Space` | Говорить с Верой (ещё раз — закончить) |
| `Ctrl+Alt+S` | «Что у меня на экране?» |

## Сборка из исходников

```bash
npm install
npm start            # запустить
npm run check        # синтаксис + юнит-тесты логики
npm run dist         # Windows: dist/Vera-Setup-x.y.z.exe и Vera-Portable-x.y.z.exe
npm run sprites      # перегенерировать пиксель-арт (нужен Python 3 + Pillow)
```

Установщик собирается workflow `.github/workflows/build.yml` на `windows-latest` при каждом пуше;
артефакт прикрепляется к сборке, а файлы публикуются в релиз `v<версия из package.json>`.
Чтобы выпустить новую версию — подними `version` в `package.json`.

## Устройство проекта

```
src/main/          главный процесс Electron
  main.js          окна, трей, горячие клавиши, уведомления, IPC
  agent.js         цикл агента: история, вызовы модели и инструментов, эмоции
  providers.js     OpenRouter / OpenAI (SDK openai) и Anthropic (SDK @anthropic-ai/sdk), стриминг + tool use
  tools.js         инструменты: напоминания, память, ПК, скриншот, погода, буфер, команды
  reminders.js     планировщик напоминаний и повторов
  memory.js        долгая память
  voice.js         STT (OpenAI/Groq) и TTS (OpenAI/ElevenLabs)
  personas.js      характеры, системный промпт, готовые реплики
  store.js         настройки и зашифрованные ключи
src/preload/       безопасный мост contextBridge
src/renderer/
  pet.*            окно-питомец: спрайт, мимика, пузырь, перетаскивание
  audio.js         микрофон + VAD → WAV, очередь озвучки с липсинком, звуки
  app.*            окно чата, напоминаний, памяти и настроек
  assets/vera/     слои пиксель-арта (генерируются tools/gen_sprite.py)
tools/gen_sprite.py  генератор спрайта Веры
scripts/check.js     проверки
```

## Приватность

- Сообщения отправляются только выбранному тобой провайдеру; голос — выбранному STT/TTS-сервису.
- Скриншот делается только по твоей просьбе (или когда ты разрешил Вере смотреть на экран и попросил об этом).
- История чата, память и напоминания лежат в `%APPDATA%\Vera` (кнопка «Папка данных» в настройках).
