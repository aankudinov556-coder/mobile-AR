## 1. ✅ ядро / 📝 сборка Android: вместо запуска приложения в чате появляется JSON

**Симптом:** «открой Telegram» → в чате `{"name": "open_app", …}`, ничего не открывается.
Провайдер — **OpenRouter**. Модель неизвестна — ⏳ пригодится скриншот JSON и название модели.

**Диагноз:**
- Запуск приложений в `PhoneTools.OpenApp` устроен правильно.
- Модель написала вызов **текстом**, а не настоящим `tool_call`. Так делают модели OpenRouter
  без поддержки function calling (часто бесплатные `…:free`).

**Правки:**
1. **Резервный разбор вызова из текста.** `{"name": …, "arguments"|"parameters": …}`, ```` ```json ````,
   `<tool_call>…</tool_call>` выполнять как настоящий вызов, а JSON из ответа убирать. Тесты.
   Этот же разбор понадобится для локальных моделей (п. 7).
2. **Выбор модели.**
   - Помечать модели OpenRouter без `tools` и предупреждать при выборе.
   - На ошибку 400 «tools not supported» — понятный текст с советом сменить модель.
3. **Диагностика.** Переключатель «Журнал запросов»: сырые ответы пишутся в файл.
4. **`open_app`:**
   - если приложение не найдено — чип «не нашла» с выбором из списка;
   - логировать ошибки `StartActivity`.

## 7. ✅ Локальные LLM на ПК — встроенный движок

**Решение:** движок **внутри Веры**, без сторонних программ. **LLamaSharp** = llama.cpp для .NET, модели формата GGUF.

- **Проект `Vera.LocalLlm`** — только для ПК.
  - Провайдер `local` с тем же интерфейсом `ILlmProvider`: стриминг, стоп, история.
- **Каталог моделей в настройках.** Скачивание с Hugging Face: прогресс, докачка, проверка контрольной суммы.
  - Хранилище: `%LOCALAPPDATA%\VeraAssistant\models`.
  - Рекомендации — instruct-модели 3–8B в квантовании Q4_K_M, хорошо знающие русский и умеющие вызывать инструменты
    (например, семейство Qwen Instruct).
  - Можно добавить свой GGUF-файл.
- **Подбор под железо.** Определять RAM, видеокарту и VRAM и советовать размер модели.
  - Ускорение: CUDA (NVIDIA) или Vulkan (AMD/Intel), иначе CPU.
  - Библиотеки ускорения докачиваются по требованию, чтобы установщик не разрастался.
- **Инструменты.** Описания инструментов передаются в шаблоне чата, ответ разбирается парсером из п. 1:
  напоминания, ПК-команды и память работают и с локальной моделью.
- **Параметры:**
  - размер контекста;
  - слои на GPU;
  - выгружать модель из памяти после N минут простоя.
- **Гибрид:** «сначала локально, если не справилась — облако» (по желанию).
- **Android:** пока не планируем (тяжело для телефона). Позже — подключение телефона к модели ПК по локальной сети (связано с п. 9.4).

## 8. ✅ Офлайн-голос на ПК: Vosk + Whisper

**Решение:** **Vosk** слушает слово «Вера», **Whisper** распознаёт команду. Плюс улучшения, которые лучше Vosk в своих задачах.

| Задача | Модуль | Почему |
|---|---|---|
| Слово-активатор «Вера» | **Vosk** (NuGet `Vosk`) + малая русская модель ~45 МБ, режим грамматики `["вера", "верочка", "[unk]"]` | постоянно слушает почти без нагрузки, полностью офлайн, ничего не уходит в облако |
| Распознавание команды | **Whisper.net** (whisper.cpp), модели base / small / medium | точность близка к облачной; на CPU small — 1–2 с на фразу, на GPU быстрее |
| Начало и конец речи | **Silero VAD** (ONNX Runtime) | надёжнее порога громкости, меньше ложных срабатываний |
| Голос Веры офлайн | **Piper** — нейросетевой TTS с русскими голосами | быстрый, работает без интернета; липсинк по звуку как сейчас |

- В настройках переключатель **«Офлайн-голос»**. У каждого модуля статус, кнопка «Скачать», размер, тест.
- Модели качаются по требованию, в установщик не входят.
- Комбинации: например, Vosk для «Вера» + облачное распознавание команд. Всё равно экономит деньги — в облако
  больше не отправляется каждая услышанная фраза.
- **Альтернатива на проверку:** **sherpa-onnx** — в одной библиотеке VAD, распознавание, TTS и поиск ключевых слов,
  есть .NET и Android. Проверить наличие качественных русских моделей. Если подойдёт — тот же офлайн-голос
  придёт и на Android.
- **Android (позже):** Vosk для слова «Вера» на устройстве. Распознавание средствами телефона уже есть.

## 9. 📝 Новые полезные функции

### 9.1 ✅ Веб-поиск для всех моделей
- Инструменты ядра `web_search` и `read_page`: Вера ищет и читает страницы с любым провайдером,
  включая локальную модель. Источники показываются ссылками в чате.
- Поиск: бесплатный вариант без ключа и API с ключом (Tavily / Brave / Serper — у них есть бесплатные лимиты).
  ⏳ Выбор при реализации.
- Из страницы извлекается основной текст, длина ограничивается.

### 9.2 ✅ ПК / 📝 телефон: файлы и документы в чат
- **ПК:** перетаскивание в окно чата или кнопка «📎». **Телефон:** выбор файла и «Поделиться → Вера».
- **Форматы:** PDF, DOCX, TXT/MD/CSV, картинки (через vision).
- **Длинные документы:** разбиение на части, пересказ, вопросы по документу.
- **Ограничения:** предупреждение о размере и стоимости.

### 9.3 Утренняя сводка + календарь
- В заданное время (или при первом включении ПК / разблокировке телефона) Вера рассказывает:
  - погоду;
  - напоминания и события на сегодня;
  - короткую мотивашку в своём характере.
- **Google Календарь** через вход в аккаунт Google:
  - читать события;
  - создавать события из чата (инструмент `create_event`).
- **Android:** вариант с календарём устройства.

### 9.4 Синхронизация ПК ↔ телефон — схема одобрена

- **Связка:**
  1. ПК: «Настройки → Синхронизация → Привязать телефон» — Вера показывает QR-код
     (адрес ПК в сети + одноразовый ключ + отпечаток ПК).
  2. Телефон сканирует код, устройства обмениваются ключами и запоминают друг друга. Есть кнопка «Отвязать».
- **Связь:**
  - мини-сервер синхронизации в Вере на ПК, доступный только в локальной сети;
  - телефон находит ПК автоматически (mDNS), даже если сменился IP;
  - всё шифруется, данные ходят только между своими устройствами.
- **Когда:**
  - при открытии приложения;
  - сразу после изменения, если оба онлайн;
  - в фоне на Android примерно раз в 15 минут (WorkManager);
  - кнопкой «Синхронизировать сейчас».
  - Без связи каждое устройство работает само и догоняет при следующей встрече.
- **Что синхронизируется:**
  - память;
  - напоминания;
  - история чата (отключаемо);
  - характер, имя, скин, голос;
  - API-ключи — только по желанию и с подтверждением.
  - **Не синхронизируются:** горячие клавиши, позиция питомца, микрофон.
- **Слияние:**
  - каждая запись хранит id, метку изменения (логические часы) и устройство; удаления передаются;
  - между устройствами ходят только изменения с прошлой синхронизации;
  - конфликт — побеждает более позднее изменение;
  - история чата просто складывается по времени.
- **Напоминания:**
  - каждое устройство ставит свои будильники и звенит без связи;
  - где звенеть: на обоих / только телефон / только ПК / **«там, где я сейчас»** (ПК, если был активен последние минуты);
  - «Готово» на одном устройстве отменяет будильник на другом, «+10 мин» переносит на обоих;
  - ограничение: без связи второе устройство может прозвенеть.
- **Интерфейс:**
  - статус «Синхронизировано N мин назад · ПК „…“»;
  - список устройств;
  - переключатели «что синхронизировать» и «где звенеть».
- **Вне дома — ОТЛОЖЕНО** до завершения остальных пунктов. Предпочтительный вариант — Tailscale (устройства в одной
  «домашней» сети через интернет). Альтернативы: зашифрованная облачная папка, свой ретранслятор.

## 10. 📝 Характер и развлечения

### 10.1 Фокус-режим / помодоро
- Таймер работы и перерыва (по умолчанию 25/5, настраивается). У Веры «рабочая» мимика, на перерыве она зовёт размяться.
- **ПК (по желанию):** замечает отвлечение — игры, YouTube — по заголовку активного окна и подкалывает.
- **Статистика:** фокус за день и неделю.

### 10.2 Реакции на события
- **Ночь:** после 1:00 гонит спать.
- **Перерыв:** после 2 часов без перерыва зовёт отдохнуть.
- **Батарея:** замечает низкий заряд (ноутбук и телефон).
- **Возвращение:** «о, вернулся» после простоя.
- **Игры:** полноэкранная игра → тихий режим (не мешает, не говорит).
- **Ошибки на экране:** только по явному разрешению, периодический взгляд выключен по умолчанию.
- Каждую реакцию можно выключить. Режим «не беспокоить».

### 10.3 Мини-игры и настроение
- **Игры:** камень-ножницы-бумага, «угадай число», загадки и викторина от модели.
- **Шкала настроения 0–100:**
  - что влияет: общение, похвала, тык, выполненные напоминания, долгое игнорирование;
  - на что влияет: случайные реплики, мимика, приветствия.
- **Небольшие достижения:** «неделя без пропущенных напоминаний» и т.п.
