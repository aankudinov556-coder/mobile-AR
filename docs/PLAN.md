## 1. 📝 Android: вместо запуска приложения в чате появляется JSON

**Симптом:** «открой Telegram» → в чате `{"name": "open_app", …}`, ничего не открывается.
Провайдер — **OpenRouter**. Модель неизвестна — ⏳ пригодится скриншот JSON и название модели.

**Диагноз (по коду):**
- Запуск приложений в `PhoneTools.OpenApp` устроен правильно.
- Модель написала вызов инструмента **текстом**, а не настоящим `tool_call`. Так делают модели OpenRouter
  без поддержки function calling (часто бесплатные `…:free`), поэтому ядро ничего не выполняет.

**Правки:**
1. **Резервный разбор вызова из текста.** JSON вида `{"name": <известный инструмент>, "arguments"|"parameters": …}`,
   блоки ```` ```json ```` и `<tool_call>…</tool_call>` в ответе выполнять как настоящий вызов, а сам JSON из ответа убирать.
   Покрыть тестом.
2. **Выбор модели.**
   - В списке моделей OpenRouter помечать модели без `tools` и предупреждать при выборе.
   - На ошибку 400 «tools not supported» — понятный текст с советом сменить модель.
3. **Диагностика.** Переключатель «Журнал запросов»: сырые ответы последних ходов пишутся в файл.
4. **`open_app`:**
   - если приложение не найдено — чип «не нашла» с выбором из списка;
   - логировать ошибки `StartActivity`.

## 2. Скины и выбор в настройках

### 2.1 📝 Скин «halo» — нарисован пользователем, вторым скином

**Решение:** добавить **вторым скином** рядом с пиксельной Верой и сделать **выбор в настройках** на ПК и на Android.
На **телефоне она меньше**.

**Что уже готово (✅):**
- 6 поз вырезаны из листа: `assets/skins/halo/*.png` + `manifest.json`. Скрипт нарезки — `tools/skins/cut_sheet.py`.
- Превью: `docs/skins/halo/`.

**Ядро (`Vera.Core`):**
- Модель скина в двух вариантах:
  - **послойный** — текущая пиксельная Вера: слои 64×72, мимика собирается из глаз, рта и рук;
  - **покадровый** — «halo»: каждая эмоция и состояние показываются готовой позой.
- Таблица «эмоция/состояние → поза»:
  | Эмоция или состояние | Поза |
  |---|---|
  | neutral, smug, говорит | `shrug` |
  | think, модель думает | `think_sit` |
  | happy, laugh | `laugh` |
  | дразнится, shy | `giggle` |
  | ожидание на панели чата (Android) | `sit` |
  | sleepy, долгий простой | `lie` |
- Настройки: `Skin` — `"vera"` | `"halo"`; `MobileMascotScale` — размер на телефоне.
- Тесты на выбор позы.

**ПК (`Vera.Desktop`):**
- Вкладка «Настройки → Вера на экране» → выбор **Пиксельная Вера / Halo**, смена на лету.
- Рендер покадрового скина:
  - картинка с плавным масштабированием — арт не на пиксельной сетке, поэтому без NearestNeighbor;
  - прозрачное окно, клики по прозрачным местам проходят насквозь.
- Анимации без новых кадров:
  - речь — лёгкое покачивание и подпрыгивание;
  - смена эмоции — короткий «поп»;
  - моргание — только когда будет кадр «глаза закрыты».

**Android (`Vera.Mobile`):**
- Выбор скина в «Настройках».
- **Размер меньше:** на панели ввода около **96–110 dp** по высоте в позе `sit`, против нынешней Веры.
- Ползунок «Размер Веры» в настройках: маленький / средний / крупный.
- Сидит на верхнем краю панели ввода справа и не закрывает кнопки микрофона и отправки (как в макете).
- Тап — реплика, долгий тап — голос. Касания мимо её силуэта проходят к кнопкам.

**⏳ Кадры от автора** — для полной мимики, в том же размере и стиле, можно одним листом:
- рот открыт (речь);
- глаза закрыты (моргание);
- удивление;
- злость / «>_<»;
- «слушаю» (голосовой ввод).

## 3. 🎨 → 📝 Поза «сидит на полу» для пиксельной Веры

Концепт готов: `docs/concepts/vera_floor.*`, генератор `tools/concepts/gen_concepts.py`.
Ноги поджаты, ладошки на коленях, тень, искорки.

**Встраивание:**
- **Спрайт:** слои `floor_<pose>` в `tools/gen_sprite.py`.
- **Ядро:** параметр позы `stand` | `bar` | `floor` в `VeraSprite`.
- **ПК:** садится на пол при простое, встаёт при наведении или клике. Опция «Садиться, когда скучно».
- **Android:** на пустом чате сидит по центру, с началом диалога запрыгивает на панель ввода.
