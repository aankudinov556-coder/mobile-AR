# Вера v2.3.0 — ПК (портативная, пре-релиз)

Только Windows 10/11 x64, без установщика: распакуй `Vera-Portable-2.3.0.zip` и запусти `Vera\Vera.exe`.
Настройки, переписка и модели — те же, что в v2.2.0.

## Новое
- **Редизайн окна:**
  - тема по скину: «золото нимба» на чёрном для halo и чиби, розовая — для пиксельной Веры;
  - кнопки и карточки в стиле стикеров;
  - в шапке портрет Веры, лицо меняется вместе с эмоцией ответа;
  - у каждого ответа в чате — аватарка с эмоцией;
  - в строке состояния — когда последний раз синхронизировался телефон.
- **Новый скин «Halo — чиби-стикеры»** из присланного листа: говорит (рот открывается), смеётся, удивляется, злится, машет.
  Выбор: Настройки → Вера → Скин.
- **Синхронизация с телефоном (сторона ПК):**
  - Настройки → Телефон → «Привязать телефон» показывает QR-код;
  - синхронизируются память, напоминания, история чата, характер, имя и скин; API-ключи — по желанию;
  - напоминания звенят на обоих, только на ПК, только на телефоне или «там, где я сейчас»;
  - связь только в домашней сети, всё шифруется.

## Важно
- **Телефонная часть синхронизации придёт с новой сборкой Android.** Текущая Вера для Android (v2.0.0) подключаться ещё не умеет.
- При первом включении «Принимать телефон» Windows спросит разрешение брандмауэра — выбери «Частные сети».

Полный план и статус — в `docs/PLAN.md`.
